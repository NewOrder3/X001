## 一、美术风格与技术标准

### 1.1 风格定调（已决策：手绘 2D）

| 维度 | 规范 |
|------|------|
| **总体风格** | 手绘 2D，温暖治愈、有绘本感（参考《Spiritfarer》《GRIS》《纪念碑谷》） |
| **场景气质** | 中式水彩海洋质感 + 《Don't Starve》的场景层次感 |
| **叙事基调** | 温暖互助、文明重建，避免 Frostpunk 式沉重压抑 |
| **角色表现** | 强表现力、有温度，幸存者不是"无脸工具人"（参考《Spiritfarer》角色） |
| **色彩体系** | 冷暖并置：海洋冷蓝/青绿为主基调，木筏与暖光（篝火、室内）提供温度对比 |
| **线条规范** | 主美统一线条粗细与质感（建议：主结构粗线、细节细线，圆润收口） |
| **光影规则** | 平面色块 + 柔和渐变投影；昼夜/天气通过整体色温与光罩实现，不依赖复杂打光 |

### 1.2 分辨率与多平台适配（关键约束）

| 规格 | 要求 |
|------|------|
| **横版基准** | 1920×1080（生存系统、UI 均以此为基准） |
| **竖屏下限** | 手机竖屏 375px 宽可正常显示（小游戏/移动端） |
| **分辨率上限** | PC 横屏 1920px |
| **缩放策略** | UI/图标矢量或高质量位图，支持 0.67x（1280×720）等比缩放 |
| **推荐做法** | 核心场景、角色、Boss 用高分辨率源文件（≥2x 基准），UI 组件用 9-patch/矢量 |

### 1.3 交付格式建议

| 资源类型 | 推荐格式 | 备注 |
|----------|----------|------|
| 场景/立绘/角色 | PNG（带透明通道，分层 PSD 源） | 主美保留分层源 |
| UI 图标/组件 | SVG / PNG（@1x @2x） | 通用图标优先 SVG |
| 动效/特效 | 序列帧 PNG 或 Spine/骨骼 | 手绘帧动画或骨骼动画二选一，需 MVP 前定 |
| 大地图（六边形） | 拼合瓦片 PNG + 数据 | 按海域瓦片拆分，避免单张超大图 |

### 1.4 优先级分级

- **P0（MVP 必需）**：验证核心循环"探索→收集→建造→招募→战斗→成长"所需资源
- **P1（核心体验）**：完整核心循环、主要系统界面、主要伙伴/Boss
- **P2（扩展内容）**：全海域、全伙伴、全 Boss、社交层、图鉴等

## 五、美术制作规范与交接标准

| 规范项 | 要求 |
