## 一、核心体验与循环

### 1.1 游戏核心体验

> 一款融合模拟经营、卡牌构筑与大地图探险的末日海洋生存游戏。玩家从浩劫中苏醒，孤身一人置身于残破竹筏之上，收集资源、扩建方舟、招募伙伴、构筑卡牌、讨伐海怪，从一叶扁舟成长为末日海洋的传奇舰队。

```
                                  │   │   │ ⚓ │   │   │
```

### 2.2 建造物分类

| 大类 | 功能定位 | 示例建筑 | 说明 |
|------|----------|----------|------|
| **基础结构** | 扩展竹筏面积 | 甲板、浮筒 | 每扩展一格消耗木材+绳索 |
| **生存设施** | 维持伙伴存活 | 蒸馏器、种植箱、篝火 | 产出食物/淡水/温度 |
| **生产设施** | 加工资源 | 锯木台、熔炉、纺车 | 原料→加工材料 |
| **存储设施** | 增加资源上限 | 木箱、储水罐、仓库 | 超上限资源会消失 |
| **功能设施** | 解锁新系统 | 船舵（航行）、工坊（卡牌升级）、医疗站 | 推动游戏进程的关键建筑 |
| **防御设施** | 战斗辅助 | 鱼叉炮、加固围栏 | 提供战斗增益/防御值 |
| **装饰设施** | 提升伙伴士气 | 吊床、旗帜、盆栽 | 美观+伙伴加成 |

## 三、伙伴卡牌系统（核心创新）

### 3.1 系统概述

伙伴卡牌系统是本作的策略核心。每位招募的幸存者都是一张可养成、可搭配的卡牌/棋子，玩家需要在有限的出战位中构筑最优组合。

### 3.2 伙伴卡牌数据结构

```
┌──────────────────────────────────────────────┐
│                                              │
│   ╔══════════════════════════════════╗        │
│   ║     伙伴卡牌：老陈                 ║        │
│   ║                                  ║        │
│   ║  [头像]  稀有度：★★★（稀有）      ║        │
│   ║          定位：建造者             ║        │
│   ║          等级：Lv.12              ║        │
│   ║                                  ║        │
│   ║  ┌──────────────────────────┐   ║        │
│   ║  │ 主动技能：紧急抢修          │   ║        │
│   ║  │ 立即修复所有破损建筑        │   ║        │
│   ║  │ 冷却：3 次航行             │   ║        │
│   ║  └──────────────────────────┘   ║        │

│   ║  被动能力：建造消耗 -15%         ║        │

```

### 3.3 伙伴定位与类型

| 定位 | 图标 | 核心作用 | 主动技能方向 | 被动能力方向 |
|------|------|----------|-------------|-------------|
| **收集者** | 🎣 | 资源采集效率 | 范围内自动收集资源 | 采集时额外获得资源 |
| **建造者** | 🔨 | 建造加速与维护 | 紧急修复/快速建造 | 建造消耗降低 |
| **战斗员** | ⚔️ | 讨伐海怪主力 | 高伤害单体/群体攻击 | 攻击力/暴击加成 |
| **守护者** | 🛡️ | 保护竹筏与伙伴 | 全队护盾/减伤 | 防御力/生命加成 |
| **支援者** | 💊 | 生存维持与治疗 | 恢复伙伴生命/体力 | 资源消耗降低 |

### 3.4 卡牌品质与获取

| 品质 | 颜色 | 初始数值倍率 | 技能强度 | 获取方式 |
|------|------|:---------:|:------:|----------|
| 普通 ★ | 灰 | 1.0× | 基础 | 航行中随机救援 |
| 稀有 ★★ | 蓝 | 1.3× | 较强 | 荒岛救援 / 特定事件 |
| 精英 ★★★ | 紫 | 1.6× | 强力 | Boss 战后解救 / 隐藏事件 |
| 传说 ★★★★ | 金 | 2.0× | 唯一 | 主线剧情 / 隐藏条件达成 |

### 3.5 伙伴养成：喂养升级

```
伙伴升级资源消耗：

  Lv.1  ──→ Lv.5   基础资源（食物/木材/铁锭）
  Lv.5  ──→ Lv.10  基础资源 + 海兽鳞片（区域 Boss 掉落）
  Lv.10 ──→ Lv.15  基础资源 + 海兽精华（精英 Boss 掉落）
  Lv.15 ──→ Lv.20  基础资源 + 深海结晶（传说 Boss 掉落）

每升 1 级：主动技能冷却 -1%，基础数值 +5%
每 5 级达成：解锁/强化被动能力
每 10 级达成：主动技能升级（效果翻倍或机制变化）
```

> **设计意图**：Boss 掉落的稀有资源是伙伴升级的关键门槛材料。这形成了"打 Boss → 获得稀有材料 → 升级伙伴 → 能打更强的 Boss"的成长飞轮，而非单纯的数值膨胀。

### 3.6 编队与出战

```
出战位设计：

┌──────────────────────────────┐
│         编队界面               │
│                              │
│   出战位 1: [老陈 🔨 Lv.12]  │ ← 建造者
│   出战位 2: [小美 🎣 Lv.10]  │ ← 收集者
│   出战位 3: [阿武 ⚔️ Lv.15]  │ ← 战斗员
│   ----- 以下未解锁 -----      │
│   出战位 4: 🔒（竹筏 Lv.5 解锁）│
│   出战位 5: 🔒（工坊 Lv.2 解锁）│
│                              │
│   [确认编队]  [自动推荐]      │
└──────────────────────────────┘

出战位 = 战斗中上场的伙伴数量
待命伙伴 = 留在竹筏上提供被动加成，不参与战斗

出战位解锁条件：
- 初始：1 个
- 竹筏 Lv.2：2 个
- 竹筏 Lv.4：3 个
- 工坊 Lv.2：4 个
- 方舟形态：5 个
```

### 3.7 卡牌组合策略

伙伴定位存在组合加成，鼓励策略搭配而非纯数值堆叠：

| 组合 | 名称 | 效果 |
|------|------|------|
| 收集者 ×2 | "双人拾荒" | 全队采集效率 +25% |
| 战斗员 + 守护者 | "攻守一体" | 战斗员攻击 +20%，守护者防御 +20% |
| 建造者 + 支援者 | "巧匠后勤" | 建造时间 -30%，资源消耗 -15% |
| 三种不同定位 | "全能小队" | 全队全属性 +10% |
| 五位满编 | "方舟之力" | 全队全属性 +25% |

## 四、战斗系统

### 4.1 战斗触发

战斗不是随时发生，而是在以下明确节点触发：

| 触发方式 | 说明 | 可否跳过 |
|----------|------|:------:|
| **区域 Boss** | 每个海域有一个驻守 Boss，进入海域后可挑战 | 可暂不挑战 |
| **航行遭遇** | 危险海域航行中有概率遭遇海怪 | 可逃跑（损失燃料） |
| **剧情 Boss** | 关键剧情节点强制战斗 | 不可跳过 |
| **讨伐任务** | 据点发布的可选讨伐 | 完全可选 |

### 4.2 战斗模式：轻量策略回合制

选择回合制而非实时动作，原因：
- 适配泛用户：不需要操作技巧，只需要策略决策
- 适配触屏：点击选择即可，不依赖精准操作
- 适配多平台：回合制在所有平台表现一致
- 卡牌策略深度：回合制最能展现卡牌搭配的策略性

```
┌──────────────────────────────────────────────┐
│                                              │
│          🦑 深渊巨鱿  HP ████████░░ 80%        │
│                                              │
│     ┌──────────────────────────────┐         │
│     │                              │         │
│     │         [海怪立绘]            │         │
│     │                              │         │
│     └──────────────────────────────┘         │
│                                              │
│   出战伙伴：                                  │
│   ┌──────┐ ┌──────┐ ┌──────┐               │
│   │ 老陈  │ │ 小美  │ │ 阿武  │               │
│   │ HP 80 │ │ HP 55 │ │ HP 90 │               │
│   │ ATK45 │ │ ATK30 │ │ ATK70 │               │
│   │ 技能就绪│ │ 技能冷却│ │ 技能就绪│              │
│   └──────┘ └──────┘ └──────┘               │
│                                              │

│   [阿武 - 普通攻击]  [阿武 - 旋风斩]          │

│                                              │
│   ⚠️ Boss 下回合将释放"深海漩涡"！            │

```

### 4.3 Boss 设计框架

| Boss 类型 | 出现阶段 | 特点 | 掉落 |
|-----------|----------|------|------|
| **小型海兽** | 阶段一 | 单个目标，1-2 个技能 | 海兽鳞片、基础资源 |
| **区域 Boss** | 阶段二 | 中等难度，3-4 个技能 | 海兽精华、伙伴经验 |
| **精英 Boss** | 阶段三 | 高难度，多阶段战斗 | 深海结晶、稀有卡牌 |
| **传说 Boss** | 终局 | 极难，需要特定策略 | 传说材料、终极蓝图 |

### 4.4 战斗数值框架

```
基础公式：

伤害 = 伙伴 ATK × 技能倍率 × (1 + 属性克制加成) - Boss DEF

属性克制（简易三属性循环）：
  力量 ⚔️ ──克制──→ 敏捷 🏃
    ▲                │
    │                ▼
  防御 🛡️ ←──克制── 力量 ⚔️

每位伙伴和 Boss 拥有一个主属性
克制关系：伤害 +30%
被克制关系：伤害 -15%

伙伴生存：
- 伙伴 HP 归零 → 该伙伴本场战斗无法行动
- 全部伙伴 HP 归零 → 战斗失败
- 战斗失败惩罚：竹筏耐久度 -10%，需要修复（不删档，不丢伙伴）
```

### 4.5 战斗奖励设计

```
Boss 击败后的奖励三件套：

① 固定掉落：海兽材料（鳞片/精华/结晶）
   → 用于伙伴升级的关键材料

② 随机掉落：稀有资源/蓝图碎片/卡牌经验
   → 给予不确定性的兴奋感

③ 首次击败奖励：独特装饰品/剧情解锁/隐藏伙伴
   → 给予"只有第一次才有的"独特获得感
```

## 五、资源系统与生产链

### 5.1 资源分类

| 大类 | 用途 | 示例 |
|------|------|------|
| **基础资源** | 建造竹筏、日常消耗 | 木材、石材、纤维、废铁 |
| **加工资源** | 高级建造、设施升级 | 木板、绳索、铁锭、布匹 |
| **生存资源** | 维持伙伴存活 | 淡水、食物、燃料 |
| **战斗资源** | 伙伴升级、卡牌强化 | 海兽鳞片、海兽精华、深海结晶 |
| **特殊资源** | 解锁隐藏内容 | 蓝图碎片、古代文物、漂流日记 |

### 5.2 资源循环模型

```
┌─────────────────────────────────────────────────────────┐
│                     资源流转全景                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  海面拾荒/采集                                            │
│      │                                                  │
│      ▼                                                  │
│  ┌────────┐    加工     ┌────────┐    建造     ┌────────┐ │
│  │ 基础资源 │ ────────→ │ 加工资源 │ ────────→ │ 竹筏扩建 │ │
│  └───┬────┘             └────────┘             └────────┘ │
│      │                                                    │
│      ├──→ 生存消耗（食物/淡水/燃料）                        │
│      │                                                    │
│      └──→ ┌──────────────┐                                │
│           │ Boss 战斗产出  │                               │
│           │ 海兽材料       │                               │
│           └──────┬───────┘                                │
│                  │                                        │
│                  ▼                                        │
│           ┌──────────────┐                                │
│           │ 伙伴喂养升级   │ ──→ 伙伴战力 ↑                 │
│           └──────────────┘         │                       │
│                                    │ 能打更强的 Boss        │
│                                    ▼                       │
│                           回到 Boss 战斗产出（正向循环）      │
└─────────────────────────────────────────────────────────┘
```

### 5.3 核心生产链

#### 建造链
```
木材 ──→ [锯木台] ──→ 木板 ──→ 竹筏扩展 + 建筑建造
废铁 ──→ [熔炉]   ──→ 铁锭 ──→ 高级建筑 + 引擎零件
纤维 ──→ [纺车]   ──→ 绳索 ──→ 渔网 + 船帆 + 竹筏扩展
产出的食物/淡水/燃料 → 生存维持 + 伙伴喂养
```

#### 伙伴成长链
```
Boss 掉落 → 海兽鳞片 ──→ Lv.5-10 升级门槛
Boss 掉落 → 海兽精华 ──→ Lv.10-15 升级门槛  + 技能解锁
```

## 七、生存系统（精简版）

### 7.1 定位变化

在统一后的核心玩法中，卡牌构筑与 Boss 战斗是体验主轴，生存系统从原先的"核心压力面"调整为**资源消耗出口**和**节奏调节器**。五项指标简化为三项，惩罚机制更加温和。

### 7.2 三项生存指标

| 指标 | 满值 | 消耗 | 归零效果（非致命） | 恢复方式 |
|------|:----:|------|-------------------|----------|
| **补给** 🥫 | 100 | 随时间消耗 | 伙伴工作效率 -50% | 消耗食物+淡水 |
| **耐久** 🔧 | 竹筏耐久 | Boss 战/暴风雨 | 部分设施暂时失效 | 消耗木材+铁锭修复 |
| **士气** ❤️ | 100 | 战斗失败/负面事件 | 伙伴战斗属性 -30% | 装饰品/成功事件/休息 |

**删除的指标**：饥饿、口渴合并为"补给"；体力由出战位和航行限制自然控制；温度由竹筏等级和设施自动管理，不再作为玩家主动管理的指标。

### 7.3 生存压力曲线

```
生存压力

 高 │                                          ╭─阶段三
    │                                   ╭──────╯  Boss 战密集
    │                           ╭──────╯         需要大量补给和耐久
    │                    ╭─────╯
 中 │             ╭─────╯        阶段二
    │      ╭─────╯              伙伴增加 → 消耗增加
    │ ╭───╯                      但产能也在提升
 低 │─╯
    │ 阶段一
    │ 单人消耗极少              ──────────────────────→ 游戏进程
    │ 几乎不存在生存压力
    └─────────────────────────────────────────────────────

设计意图：生存压力随游戏进程自然上升，而非前期劝退
```

## 九、MVP 定义

### 9.1 MVP 范围

```
MVP 包含：
✅ 竹筏建造：Lv1 → Lv3（3×3 → 5×6 网格）
✅ 可建造设施：7-10 个（集雨器、篝火、锯木台、熔炉、纺车、木箱、船舵）
✅ 大地图：3-4 个海域格（起始海域 + 2-3 个可探索海域）
✅ 伙伴卡牌：3-4 张不同定位的伙伴卡
✅ 战斗系统：1 个教学 Boss + 1 个区域 Boss
✅ 资源系统：基础/加工/生存三类资源 + 海兽鳞片
✅ 伙伴升级：Lv.1-Lv.10 升级线路
✅ 编队：2-3 个出战位
✅ 基础交易：1 个流浪商人模板
✅ 完整核心循环验证

MVP 不包含：
❌ 完整世界地图（10+海域）
❌ 全部伙伴卡牌（仅 3-4 张）
❌ 卡牌组合加成
❌ 精英 Boss / 传说 Boss
❌ 品质突破系统
❌ 剧情系统
❌ 据点系统
❌ 社交功能
```

### 9.2 MVP 验证标准

| 验证维度 | 标准 |
|----------|------|
| **核心循环** | 测试者 20 分钟内自然完成"探索→收集→扩建→招募→战斗→成长"至少 1 轮完整循环 |
| **卡牌吸引力** | 获得新伙伴卡牌后，测试者主动查看卡牌详情并尝试编队调整 |
| **战斗乐趣** | Boss 战结束后，测试者表现出成就感（而非"终于结束了"） |
| **上手门槛** | 90% 测试者在引导阶段顺利完成所有操作 |
| **留存动机** | 测试者主动表达"还想继续玩下去" |
