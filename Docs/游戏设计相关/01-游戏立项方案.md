## 一、项目概述

### 1.1 一句话描述

**在世界被海水吞没的末日时代，带领一群幸存者，从一块木板开始，建造属于你的海上家园。**

### 1.2 产品定位

| 维度 | 定位 |
|------|------|
| **品类** | 末日生存 + 模拟经营 + 轻度策略 |
| **平台** | 多平台优先设计，不绑定单一平台（Steam / 小游戏平台 / 移动端 App） |
| **商业模式** | 买断制（Steam）或 免费+广告/内购（小游戏/移动端），具体按上架平台确定 |
| **难度基调** | **中轻度**——低上手门槛、平缓学习曲线、避免惩罚性机制 |
| **核心体验** | 从一无所有到海上城池的成长满足感，温暖互助的文明重建叙事 |
| **差异化** | 在生存玩法的辨识度和泛用户的可接受度之间找到平衡点 |
| **社交策略** | 预留可扩展社交层，根据最终平台灵活接入（详见第六章） |

### 1.3 为什么是末日海上生存？

- **题材新鲜度**：市面上末日生存多集中在陆地（僵尸、废土），纯海上题材在国内外市场均有较大空白
- **叙事张力强**：海洋天然具有孤独感、未知感和宏大感，容易建立情感共鸣
- **系统拓展空间大**：从木筏→小船→大船→漂浮城市，成长弧线清晰且富有想象力
- **视觉辨识度高**：海上场景具有极强的视觉记忆点，区别于千篇一律的农场/餐厅/废土经营
- **跨平台潜力**：核心玩法不依赖特定平台特性，便于根据发行策略灵活部署

## 二、核心概念

### 2.1 世界观概要

> **2047年，地球地质活动剧烈加剧，全球海平面在十年内上升了超过800米，99%的陆地沉入海底。残存的人类散落在曾经的群山之巅——如今不过是零星的小岛和礁石。你在一次风暴后醒来，发现自己趴在一块漂浮的木板上，身边只有几块废铁和半瓶淡水。远处，似乎有人在挥手求救……**

### 2.2 玩家角色与起始条件

- **玩家身份**：一名普通幸存者（可自定义名称和简易外观）
- **起始资源**：一块2×2的基础木筏、1个简易鱼钩、3天份的淡水、一把生锈的小刀
- **起始人口**：玩家自身 + 可救援的第一位幸存者（作为教程引导）
- **起始位置**：随机生成的温和海域（教程保护期约30分钟）

### 2.3 核心玩法循环

```
         ┌──────────────────────────────┐
         │                              │
         ▼                              │
   ┌──────────┐                  ┌──────────┐

   │ 钓鱼/拾荒  │◄─────────────────│ 航行/潜水 │
   │ 蒸馏/种植  │                  │ 事件/战斗 │
   └─────┬────┘                  └─────┬────┘
         │                              │
         ▼                              │

   │  加工生产  │ ──────────────► │  交易交换  │
   │ 生产链系统 │                  │ 商船/据点 │
   └─────┬────┘                  └─────┬────┘

   ┌──────────┐                         │
```

### 2.4 成长阶段设计

| 阶段 | 阶段名称 | 触发条件 | 核心体验 |
|------|----------|----------|----------|
| **Phase 1** | 漂流求生 | 游戏开始 | 个人生存，捡垃圾，学基础操作 |
| **Phase 2** | 小舟初成 | 首次升级木筏 | 招募首批幸存者，分工协作 |
| **Phase 3** | 船队成型 | 拥有3+艘船 | 建立生产链，开始交易 |
| **Phase 4** | 海上据点 | 人口15+ | 防御系统，区域影响力 |
| **Phase 5** | 方舟都市 | 人口30+ | 文明重建，终极目标推进 |

## 三、玩法亮点

### 3.1 核心亮点一览

#### 🏗️ 亮点一：从一块木板到海上都市的建造进化

不是简单的"点击升级"，而是视觉上可见的物理拼接。玩家拖拽模块拼接到木筏上，看到自己的船从一块浮板逐渐变成多层甲板的海上堡垒。每一块木板、每一个房间都是玩家亲手放置的。

#### 🎣 亮点二：立体化的资源获取方式

- **海面拾荒**：漂流的木箱、残骸、垃圾（低风险，低回报）
- **钓鱼系统**：简易的点击+时机判定，不同海域不同鱼种
- **潜水探索**：潜入沉没的城市遗迹，高风险高回报
- **雨水收集**：依赖天气系统的被动资源
- **海上种植**：在船上开辟小型种植区，闭环食物链

#### 👥 亮点三：有故事的幸存者系统

不是无脸的工具人。每个可招募的幸存者有：
- **背景故事**：简短的身世文本（医生、工程师、渔民、学生等）
- **专属技能**：影响生产效率或解锁特殊建造
- **性格特质**：乐观者提升士气、悲观者消耗更多资源、领导者解锁管理功能
- **个人需求链**：除了基础生存，还有社交、娱乐等需求

#### 🌊 亮点四：动态海洋世界

- **天气系统**：晴天/阴天/暴风雨/海雾，影响能见度、航行速度、资源刷新
- **洋流系统**：海域间有方向性洋流，航行顺流加速、逆流减速
- **昼夜循环**：夜晚视野缩小，部分资源仅在夜间出现
- **海域生态**：不同海域有不同资源分布和危险等级

#### ⚡ 亮点五：小程序适配的"轻量化深度"

- **离线收益**：下线后幸存者自动执行分配的任务，上线结算
- **碎片化操作**：单次操作不超过30秒即可完成一个完整动作
- **社交轻交互**：访问好友的海上基地、赠送物资、联合对抗海盗事件
- **故事驱动**：用阶段性剧情目标替代无休止的数值膨胀

## 六、多平台适配设计

### 6.1 平台无关的核心设计原则

由于最终上架平台未定（可能为 Steam 独立发行 / 小游戏平台 / 移动端 App），核心玩法设计遵循"平台无关"原则：

| 设计原则 | 说明 |
|----------|------|
| **交互最小化** | 核心操作不超过点击+拖拽，适配触屏/鼠标/手柄 |
| **操作粒度弹性** | 支持5秒完成一个操作，也支持连续游玩1小时 |
| **离线友好** | 断线/退出自动保存，支持离线资源结算（适配移动场景） |
| **分辨率弹性** | UI 自适应手机竖屏（375px）到 PC 横屏（1920px） |
| **包体可伸缩** | 素材按需加载，支持小游戏的分包限制和 Steam 的完整下载 |

### 6.2 各平台差异化策略（预留）

| 平台 | 优势 | 适配策略 |
|------|------|----------|
| **Steam** | 用户付费意愿高、社区生态完善 | 买断制、成就系统、创意工坊（MOD支持） |
| **小游戏平台** | 获客成本低、社交裂变强 | 免费+广告、微信关系链、排行榜、分享奖励 |
| **移动端 App** | 用户基数大、支付便捷 | 免费+内购、推送通知、离线收益强化 |

### 6.3 社交模块可扩展性设计（重点）

社交玩法不写死在核心循环中，而是设计为**可插拔的社交层**：

```
                 ┌─────────────────────────┐
                 │     核心游戏系统          │
                 │  (生存/建造/资源/经营)     │
                 └───────────┬─────────────┘
                             │
                 ┌───────────▼─────────────┐
                 │     社交抽象接口层        │
                 │  (好友数据 / 消息 / 交易)  │
                 └───────────┬─────────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
  ┌──────▼──────┐   ┌───────▼───────┐   ┌───────▼──────┐
  │  Steam 实现  │   │  小游戏实现    │   │  App 实现     │
  │ 好友列表     │   │ 微信关系链    │   │ 手机通讯录    │
  │ 创意工坊     │   │ 分享/排行榜   │   │ 推送通知      │
  └─────────────┘   └───────────────┘   └──────────────┘
```

#### 社交功能分级

| 层级 | 功能 | 依赖度 | 说明 |
|------|------|--------|------|
| **L0 - 纯单机** | 无社交 | 无 | 核心玩法完全自洽，可独立运行 |
| **L1 - 轻度社交** | 排行榜、成就对比 | 低 | 仅读取，不写入，适配所有平台 |
| **L2 - 互助社交** | 访问基地、赠送资源 | 中 | 异步交互，不要求同时在线 |
| **L3 - 协作社交** | 联合舰队、共同事件 | 高 | 需要平台社交基础设施支持 |
| **L4 - 深度社交** | 创意工坊、玩家市场 | 很高 | Steam 专属，小游戏平台不考虑 |

#### 核心系统预留的社交接口

| 核心系统 | 预留社交扩展点 |
|----------|---------------|
| **建造系统** | "蓝图分享"——玩家可将自己的建造布局导出为蓝图，供好友参考或一键套用 |
| **资源系统** | "海上漂流瓶"——发送物资给好友，对方上线后在海上随机刷新 |
| **探索系统** | "求救信号"——遇到高难度事件可向好友发送求救，对方派遣支援船 |
| **经营系统** | "贸易航线"——与好友的基地建立贸易路线，自动交换指定物资 |
| **幸存者系统** | "幸存者派遣"——将多余的幸存者派遣到好友基地短期工作 |

> **设计原则**：以上社交功能在核心代码中仅预留数据接口和事件钩子，具体实现根据最终平台在 Phase 3 详细设计阶段确定。核心玩法不依赖任何社交功能即可完整体验。

## 七、美术风格方案

### 7.1 候选风格对比分析

策划提出三个候选方向，以下为系统性对比：

#### 方案 A：手绘 2D 风格

| 维度 | 评估 |
|------|------|
| **视觉印象** | 温暖、治愈、有"绘本感"，类似《Spiritfarer》《Gris》 |
| **适配游戏** | ★★★★★ 完美匹配"温暖互助重建文明"的叙事基调 |
| **情感传达** | ★★★★★ 手绘线条天然有温度和人情味 |
| **制作成本** | ⚠️ 中等偏高——每件道具/角色需独立绘制，但不需要超高精度 |
| **动画实现** | ★★★☆☆ 需要帧动画或骨骼动画，中等工作量 |
| **跨平台** | ★★★★☆ 2K分辨率即可涵盖所有平台，缩放不失真 |
| **市场辨识度** | ★★★★☆ 独立游戏领域已建立审美认知，玩家接受度高 |
| **海洋表现** | ★★★★★ 水彩/水墨质感天然适合海洋题材 |
| **风险** | 需要强力主美统一画风，否则容易风格割裂 |

#### 方案 B：像素风格

| 维度 | 评估 |
|------|------|
| **视觉印象** | 复古、硬核、有"游戏感"，类似《星露谷物语》《泰拉瑞亚》 |
| **适配游戏** | ★★★☆☆ 像素风与"温暖叙事"有一定风格张力 |
| **情感传达** | ★★☆☆☆ 像素天然偏向抽象和距离感，不易传达细腻情感 |
| **制作成本** | ★★★★★ 成本最低，素材可批量生成 |
| **动画实现** | ★★★★☆ 帧动画简单直接，技术门槛低 |
| **跨平台** | ★★★★★ 像素天生跨平台友好 |
| **市场辨识度** | ★★★☆☆ 像素风在独立游戏中过于常见，辨识度打折 |
| **海洋表现** | ★★★☆☆ 海洋的流动性在像素下表现受限制 |
| **风险** | 视觉上容易泯然众人，难以建立独特的品牌印象 |

#### 方案 C：剪纸风格

| 维度 | 评估 |
|------|------|
| **视觉印象** | 独特、艺术感强、具有中国文化辨识度，类似《纸境》《忍者印记》 |
| **适配游戏** | ★★★★☆ "拼凑漂浮世界"与剪纸"拼贴"有天然隐喻契合 |
| **情感传达** | ★★★★☆ 剪纸的层叠质感有独特的美学感染力 |

| **动画实现** | ★★☆☆☆ 剪纸风格的平滑动画较难实现，更依赖关键帧 |
| **跨平台** | ★★★★☆ 2D素材天然跨平台 |
| **市场辨识度** | ★★★★★ 极高辨识度，市场上几乎没有剪纸风的生存经营游戏 |

### 7.3 推荐：手绘 2D 风格

**推荐理由**：

1. **与泛用户优先策略高度匹配**——手绘的温暖质感能有效降低末日题材的沉重感，吸引泛用户
2. **叙事载体能力强**——幸存者故事线、海上风光、文明重建的史诗感，都需要手绘才能传达到位
3. **海洋题材天然优势**——水彩/水墨质感的手绘海洋，视觉上就有"想让人截图分享"的美感
4. **市场已有审美铺垫**——《Spiritfarer》《GRIS》《纪念碑谷》等作品已培养出大量手绘风受众
5. **品牌辨识度均衡**——不像像素风那么泛滥，也不像剪纸风那么冒险，是"稳中求新"的选择

**执行建议**：
- 核心视觉参考方向：《Spiritfarer》的角色表现力 + 《Don't Starve》的场景层次感 + 中式水彩的背景质感
- 主美需要统一以下规范：线条风格（粗细/质感）、色彩体系（冷暖基调）、光影规则（平面/渐变/投影）
- 优先制作"海上场景 + 木筏建造"核心视觉，作为美术风格定调稿
